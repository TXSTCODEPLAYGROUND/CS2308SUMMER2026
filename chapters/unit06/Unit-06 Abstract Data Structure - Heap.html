What is a Heap?

A complete binary tree stored in an array, satisfying the heap property: every parent ≥ both children (max-heap).

Priority Queues

OS schedulers, Dijkstra, task managers — always extract the highest priority item in O(log n).

Heap Sort

In-place O(n log n) sorting without extra memory for merges.

Top-K Problems

Find k largest/smallest in streaming data — LeetCode favorites.

Median / Sliding Window

Two heaps maintain running median in O(log n) per update.

Why popular? Simple array backing, cache-friendly, and O(log n) insert/delete — no pointers needed.

Valid & Invalid Heaps

Insert Complexity — O(log n)

Worst-case insert: how many levels can the new value climb?

Height = ⌊log₂ n⌋

Each insert bubbles up at most one level per swap. Worst case: new leaf at bottom climbs to root → O(log n) comparisons & swaps.

Build-Heap Complexity — O(n log n)

Insert n elements one-by-one: each costs O(log k) where k grows from 1 to n.

Sum of heights

Total work ≈ Σ log₂(i) for i = 1…n = O(n log n)

Insert #1 → log 1 step  ·  Insert #2 → ≤ 1 step  ·  …  ·  Insert #n → ≤ ⌊log₂ n⌋ steps

Can we build a max-heap from an array faster than n successive inserts?

O(n) bottom-up heapify

Sift-down from lastParent(n) to root — tighter than n inserts. Floyd's algorithm builds the heap in linear time.

Fact chain

① Single insert = O(log n)  →  ② n inserts = n × O(log n) = O(n log n)

void heapify(vector<int>& a) { int n = a.size(); for (int i = (n - 2) / 2; i >= 0; i--) siftDown(a, i); } void siftDown(vector<int>& a, int i) { int n = a.size(); while (true) { int l = 2*i+1, r = 2*i+2, big = i; if (l < n && a[l] > a[big]) big = l; if (r < n && a[r] > a[big]) big = r; if (big == i) break; swap(a[i], a[big]); i = big; } }

O(n) total — not O(n log n)

Most nodes are near the bottom and sift only a short distance. Summing work over all levels gives linear time.

int heapPop(vector<int>& h) { int top = h[0]; h[0] = h.back(); h.pop_back(); int i = 0; while (true) { int l = 2*i+1, r = 2*i+2, big = i; if (l < h.size() && h[l] > h[big]) big = l; if (r < h.size() && h[r] > h[big]) big = r; if (big == i) break; swap(h[i], h[big]); i = big; } return top; }

Repeatedly popping the max yields elements in descending order — reverse for ascending sort!

Heap Sort Complexity

Time: O(n log n)

Build heap: O(n log n) via inserts  +  n pops × O(log n) each = O(n log n)

Space: O(1) in-place

Sorts within the array (aside from O(n) output if collecting pops separately). No merge buffer needed.

Stable?

No — equal elements may reorder.

vs Quick Sort

Heap sort guarantees O(n log n) worst case; quicksort can degrade to O(n²).

Real-World Applications

⚡ Priority Queues

Linux CFS scheduler, hospital triage, game AI pathfinding.

std::priority_queue in C++ wraps a binary heap — push/pop in O(log n).

🗺️ Dijkstra / A*

Shortest path extracts minimum-distance node repeatedly.

Min-heap stores (distance, node) pairs — O((V+E) log V) with binary heap.

📊 Top-K Streaming

Log analysis, recommendation engines, leaderboards.

Maintain size-k heap while scanning billions of events in O(n log k).

📈 Running Median

Finance, sensor networks, live dashboards.

Max-heap (lower half) + min-heap (upper half) → median in O(log n).

🗜️ Huffman Coding

JPEG, MP3, ZIP compression trees.

Repeatedly merge two smallest frequencies using a min-heap.

🖥️ OS & Databases

Memory management, event timers, merge joins.

Timer wheels and heap-based schedulers wake the nearest deadline first.

Heaps win because they're simple, cache-friendly (array-backed), and give predictable O(log n) performance without complex balancing like red-black trees.
